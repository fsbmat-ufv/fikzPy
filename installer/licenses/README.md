These unmodified license texts accompany the open-source Qt/PySide6 runtime.
Source: Qt Base v6.11.1, https://github.com/qt/qtbase/tree/v6.11.1/LICENSES.

The build copies these texts and the notices shipped by each Python wheel
into the installed `licenses/` directory. Python's license and the original
TinyTeX/TeX Live notices are also included. Application source and build scripts
are shipped in `fikzPy-source.zip`; dependency versions and upstream source
locations are recorded in `licenses/packages.json` and `licenses/README.txt`.
